# Dadabase

A dad-joke site on the [icanhazdadjoke](https://icanhazdadjoke.com/api) API, built with Vue 3, TypeScript, Apollo Client and Pinia. It's a take-home project for [this brief](docs/brief.md).

This README is a placeholder until milestone 8. For now:

- [The spec](docs/spec.md)
- [Decisions (ADRs)](docs/adr/)
- [The journal](docs/journal/)

## Commands

```sh
npm install
npm run dev          # http://localhost:5173
npm run check        # lint, typecheck, unit tests with coverage
npm run test:e2e     # Playwright, against a build that mocks the API
npm run storybook    # http://localhost:6006
```
